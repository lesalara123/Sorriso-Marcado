# Prompts — Sorriso Marcado

Esta pasta armazena os prompts utilizados no planejamento, desenvolvimento, análise e manutenção do aplicativo Sorriso Marcado.

## Organização

| Arquivo | Finalidade |
|---|---|
| `001-analise-arquitetura.md` | Análise técnica e arquitetural do projeto |
| `002-icone-splash-screen.md` | Criação do ícone e configuração da Splash Screen |
| `003-padrao-de-desenvolvimento.md` | Instruções reutilizáveis para implementar funcionalidades |

## Padrão de documentação

Cada prompt deve conter:

- **Objetivo:** o que se pretende realizar.
- **Contexto:** informações relevantes sobre o projeto.
- **Prompt:** instrução completa enviada à IA.
- **Resultado esperado:** o que deve ser produzido.
- **Status:** planejado, em andamento, concluído ou pendente de validação.

## Boas práticas

1. Preserve o texto original dos prompts importantes.
2. Registre alterações relevantes em novos arquivos ou versões identificadas.
3. Não registre senhas, tokens, credenciais ou dados reais de pacientes.
4. Não considere um resultado validado apenas porque foi gerado pela IA.
5. Relacione cada prompt aos arquivos ou funcionalidades afetados, quando possível.

Os resultados, relatórios e análises produzidos a partir dos prompts devem ser organizados em `docs/outputs/`.
