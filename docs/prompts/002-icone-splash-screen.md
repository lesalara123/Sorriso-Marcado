# Prompt 002 — Ícone e Splash Screen

## Objetivo

Personalizar a identidade visual do aplicativo Sorriso Marcado com um ícone próprio e uma Splash Screen com fundo verde-petróleo.

## Contexto

- Projeto Android desenvolvido em Kotlin.
- Interface construída com Jetpack Compose.
- Tema principal: `Theme.Sorrisomarcado`.
- Tema de inicialização: `Theme.Sorrisomarcado.Starting`.
- Cor de fundo da Splash Screen: `#004C48`.

## Prompt utilizado

Analise a configuração atual do projeto Android Sorriso Marcado e oriente a criação de um ícone personalizado com um símbolo minimalista de dente branco sobre fundo verde-petróleo.

Configure o ícone do aplicativo para substituir o ícone padrão do Android Studio e integre-o à Splash Screen nativa do Android.

Preserve a estrutura existente do projeto, mantenha os temas corretamente configurados e verifique as dependências necessárias para a Splash Screen.

Forneça instruções passo a passo, indicando os arquivos que precisam ser alterados e como testar o resultado.

## Resultado esperado

- Ícone personalizado do aplicativo.
- Recursos do ícone adaptativo e versões para diferentes densidades de tela.
- Splash Screen com fundo `#004C48`.
- Integração com o tema principal após a inicialização.

## Arquivos relacionados
